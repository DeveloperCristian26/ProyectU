Diseño y estilo de páginas web

Introducción a CSS

CSS (Cascading Style Sheets) es el lenguaje que se usa para dar estilo a las páginas web. Permite cambiar colores, tamaños, posiciones y diseño general.

¿Para qué sirve CSS?

  • Dar color a textos y fondos
  • Diseñar layouts modernos
  • Mejorar la experiencia del usuario
  • Hacer páginas responsivas

Tipos de CSS

  • Inline: dentro del HTML
  • Interno: dentro de <style>
  • Externo: archivo .css separado

Ejemplo básico

h1 {
    color: blue;
    font-size: 40px;
}

p {
    color: gray;
}

Conceptos importantes

  • Selectores
  • Propiedades
  • Valores
  • Box Model
