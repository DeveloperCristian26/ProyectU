Introducción a HTML

HTML (HyperText Markup Language) es el lenguaje base de todas las páginas web. Se utiliza para estructurar el contenido como textos, imágenes, enlaces y secciones.

¿Para qué sirve?

  • Crear páginas web
  • Organizar contenido
  • Definir estructura visual básica

Etiquetas básicas

Algunas etiquetas fundamentales:

  • <h1> Títulos
  • <p> Párrafos
  • <a> Enlaces
  • <img> Imágenes
  • <div> Contenedores

Ejemplo básico

<h1>Hola mundo</h1>
<p>Mi primera página web</p>
