Guía de Programación

Introducción a HTML, CSS y JavaScript

¿Qué es la programación?

La programación es el proceso de crear instrucciones que una computadora puede entender y ejecutar. Estas instrucciones se escriben usando lenguajes como HTML, CSS y JavaScript.

HTML (Estructura)

HTML (HyperText Markup Language) es el lenguaje base de toda página web. Su función principal es definir la estructura y el contenido.

¿Para qué sirve HTML?
  • Crear la estructura de páginas web
  • Definir textos, imágenes y enlaces
  • Organizar el contenido en secciones
Estructura básica de HTML

Todo documento HTML sigue esta estructura:

<!DOCTYPE html>
<html>
  <head>
    <title>Mi página</title>
  </head>

  <body>
    <h1>Hola mundo</h1>
    <p>Este es un párrafo</p>
  </body>
</html>
Etiquetas importantes
  • <h1> - <h6>: títulos
  • <p>: párrafos
  • <a>: enlaces
  • <img>: imágenes
  • <div>: contenedor general
  • <span>: texto en línea
Ejemplo de enlace
<a href="https://google.com">Ir a Google</a>
Ejemplo de imagen
<img src="imagen.jpg" alt="Descripción">
Consejo

HTML no programa lógica, solo estructura. Siempre se combina con CSS y JavaScript.

CSS (Diseño y Estilo)

CSS (Cascading Style Sheets) es el lenguaje que se usa para dar estilo a las páginas web. Permite cambiar colores, tamaños, posiciones y hacer que la web sea visualmente atractiva.

¿Para qué sirve CSS?
  • Dar colores y estilos a la página
  • Organizar el diseño (layout)
  • Crear animaciones y efectos
  • Hacer la web responsive (adaptable a celular)
Formas de usar CSS
  • Inline: dentro del HTML
  • Interno: dentro de <style>
  • Externo: archivo .css (recomendado)
Ejemplo básico de CSS
h1 {
  color: blue;
  font-size: 40px;
}

p {
  color: gray;
  font-family: Arial;
}
Propiedades importantes
  • color: cambia el color del texto
  • background-color: color de fondo
  • font-size: tamaño del texto
  • margin: espacio exterior
  • padding: espacio interior
  • border: bordes
Ejemplo de caja (box model)
div {
  margin: 20px;
  padding: 10px;
  border: 2px solid black;
}
Diseño responsive

CSS permite que una página se adapte a celulares usando media queries: 

@media (max-width: 768px) {
  body {
    background-color: lightblue;
  }
}
Consejo

CSS es lo que convierte una página simple en una web profesional. Sin CSS, todo se vería plano y sin diseño.

JavaScript (Interactividad y Lógica)

JavaScript es el lenguaje que permite que una página web sea interactiva. Gracias a él puedes crear botones que responden, formularios dinámicos y aplicaciones completas.

¿Para qué sirve JavaScript?
  • Hacer páginas interactivas
  • Responder a botones y eventos
  • Validar formularios
  • Crear juegos y aplicaciones web
Ejemplo básico
<script>
  alert("Hola mundo");
</script>
Variables

Las variables guardan información:

let nombre = "Juan";
let edad = 20;
Condiciones (if)

Sirven para tomar decisiones:

let edad = 18;

if (edad >= 18) {
  console.log("Eres mayor de edad");
} else {
  console.log("Eres menor de edad");
}
Funciones

Las funciones permiten reutilizar código:

function saludar(nombre) {
  return "Hola " + nombre;
}

console.log(saludar("Ana"));
Eventos

JavaScript responde a acciones del usuario:

<button onclick="saludar()">Click</button>

<script>
function saludar() {
  alert("Hola");
}
</script>
Manipular HTML

JavaScript puede cambiar la página:

document.getElementById("titulo").innerHTML = "Nuevo texto";
Conclusión

JavaScript es el cerebro de la web. HTML estructura la página, CSS la diseña y JavaScript la hace funcional e interactiva.
