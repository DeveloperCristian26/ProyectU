¿Qué es JavaScript?

El lenguaje que da vida a las páginas web

Introducción a JavaScript

JavaScript es un lenguaje de programación que permite hacer páginas web interactivas. Es el encargado de los botones, animaciones, formularios dinámicos y mucho más.

¿Para qué sirve JavaScript?

  • Crear interactividad en páginas web
  • Validar formularios
  • Crear aplicaciones web dinámicas
  • Manipular el contenido HTML

Ejemplo básico

let nombre = "Juan";

function saludar() {
    alert("Hola " + nombre);
}

saludar();

Conceptos básicos

  • Variables (let, const)
  • Funciones
  • Eventos
  • Condicionales (if / else)
  • DOM (Document Object Model)
